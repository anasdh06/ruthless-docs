# Privacy Policy

Last Updated: August 1, 2026

## Introduction

Ruthless ("the Bot") respects your privacy. This Privacy Policy explains what information is collected, how it is used, and how it is protected.

By using Ruthless, you agree to this Privacy Policy.

## Information We Collect

The Bot may collect and store the following information when required for its functionality:

- Discord User IDs
- Discord Server (Guild) IDs
- Discord Channel IDs
- Discord Role IDs
- Discord Message IDs (only when necessary)
- Bot configuration settings
- Command usage
- Voice activity statistics (if enabled)
- Moderation logs (if enabled)

The Bot does not collect passwords, email addresses, payment information, or private Discord messages.

## How We Use Data

Collected data is used solely to:

- Provide bot features
- Store server configuration
- Process moderation actions
- Track voice activity (if enabled)
- Improve performance
- Prevent abuse

## Data Storage

Data is stored securely and only for as long as necessary to provide the Bot's services.

## Data Sharing

We do not sell, rent, or share your data with third parties unless required by law.

## Data Removal

Server administrators may request the deletion of server-related data by contacting the Bot developer.

## Security

Reasonable security measures are implemented to protect stored information. However, no system can guarantee absolute security.

## Changes

This Privacy Policy may be updated at any time. Continued use of the Bot constitutes acceptance of any changes.

## Contact

For support, contact the developer through the official support server.
